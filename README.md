# Honeypot Anti-Spam CAPTCHA for OpenCart / LiveStore

Невидимая антиспам-защита для OpenCart 3.x / LiveStore. Расширение устанавливается как тип **CAPTCHA** и отображается в `Дополнения → Дополнения → CAPTCHA`.

## Версия 1.1.0

Honeypot работает **вместе** с Google CAPTCHA, Yandex CAPTCHA или Basic CAPTCHA. Он не отключает выбранную CAPTCHA.

Оставьте текущую CAPTCHA выбранной в настройках магазина и включите Honeypot Anti-Spam как отдельное расширение. OCMOD добавляет скрытую проверку параллельно основной CAPTCHA.

## Возможности

- honeypot-поле без `display:none`;
- случайное имя ловушки;
- одноразовый токен формы;
- проверка минимального времени заполнения;
- совместная работа с Google / Yandex / Basic CAPTCHA;
- журнал e-mail, имени, IP, User-Agent, route, причины и времени;
- фильтры и статистика;
- срок хранения журнала;
- QR-код и ссылка благодарности;
- без VQMod;
- OCMOD + стандартный механизм CAPTCHA OpenCart.

Пароли и содержимое сообщений не сохраняются.

## Установка

1. Скачайте `dist/honeypot_antispam_captcha_v1.1.0.ocmod.zip`.
2. `Дополнения → Установка дополнений` → загрузите ZIP.
3. `Дополнения → Дополнения` → тип `CAPTCHA`.
4. Установите и откройте `Honeypot Anti-Spam`.
5. Включите расширение.
6. `Дополнения → Модификаторы` → нажмите обновление кеша.
7. Если нужна двухуровневая защита, **оставьте Google/Yandex/Basic выбранной основной CAPTCHA**.
8. Проверьте формы на тестовом сайте.

## Стандартные страницы

Регистрация, регистрация при оформлении, гостевое оформление, контакты, отзывы товара и возвраты — если соответствующая страница включена в стандартном списке страниц CAPTCHA.

## Совместимость

OpenCart 3.x / LiveStore 3. PHP 7.2–8.1, рекомендуемый диапазон 7.4–8.1.

Сторонние темы и OCMOD могут менять контроллеры, поэтому перед публикацией для другой сборки необходимо проверить применение модификаций.
